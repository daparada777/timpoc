# timpoc — субтитры для Adobe After Effects

Автоматическое распознавание речи и создание редактируемых субтитров прямо в After Effects.
Локальная обработка: аудио не покидает ваш компьютер.

> Статус: **этап 3 из 7 завершён** (сквозной рабочий сценарий). Ниже честно расписано,
> что уже проверено запуском, что написано, но требует проверки на вашей машине,
> и что ещё не сделано.

### Найденные и исправленные ошибки (важно: это не «красивый отчёт», а реальные баги)

1. **`faster-whisper 1.2.1` несовместим с `av 19.0.1`** — падает на
   `TypeError: open() got an unexpected keyword argument 'metadata_errors'`.
   Решение: закрепить `av<14`. В `requirements.txt` это зафиксировано.
2. **Слова отбрасывались при ненулевом смещении.** Фильтр зоны перекрытия окон
   не учитывал `offset_seconds`, поэтому при распознавании не с начала
   композиции результат был пустым. Найдено тестом на живом движке.
3. **`0.3 − 0.2 = 0.09999999999999964`** — длительность блока «проваливалась»
   под порог из-за плавающей точки. Исправлено округлением в `SubtitleBlock.duration`.
4. **Склейка коротких блоков отменяла деление по паузе** — субтитр «висел» через
   всю тишину. Введена политика границ (точка и пауза не склеиваются).
5. **Позиции 2 и 4 совпадали с 1/3/5** — требовалось пять вертикальных позиций,
   получалось три. Формула переписана.
6. **Метод `Engine.state()` перекрывался атрибутом `self.state`** → `TypeError`.
   Атрибут переименован в `project_state`.

### Почему CEP, а не UXP (проверено, не выдумано)

* After Effects **2026 = CEP 12**. UXP для AE на сегодня — только публичная бета
  (Adobe обещает публичную бету к ноябрю 2026).
* Adobe гарантирует минимум два года от беты UXP до удаления CEP; CEP выключается
  по умолчанию в декабре 2028 и удаляется в декабре 2029.
* Вывод: CEP — единственный стабильный путь сейчас. Миграция на UXP заложена
  в план, но не в первый рабочий продукт.
* Источники: блог Adobe Developer (сентябрь 2026), форумы Creative Cloud
  Developer (январь 2026).

### Почему отдельный процесс для распознавания

* After Effects не блокируется: распознавание идёт в своём процессе, панель
  раз в 300 мс спрашивает прогресс и может отменить.
* Панель CEP — браузер без доступа к CUDA; Python решает это корректно.
* Движок слушает **только 127.0.0.1** и требует случайный токен на каждый запуск.

### Как устроены субтитры в AE

**Один текстовый слой с ключами Source Text**, а не слой на каждую фразу.

* На `in` каждого блока ставим его текст, на `out` — пустую строку.
* Между ключами значение держится, поэтому субтитр виден всё своё время.
* На длинном проекте это 1 слой, а не 800 — таймлайн и производительность целы.
* Всё остаётся редактируемым средствами AE: текст, шрифт, ключи.
* Слои помечаются в `comment` меткой `timpoc|…`, поэтому «удалить только timpoc»
  не трогает ваши слои.
* Подложка — сплошной слой с экспрешеном по `sourceRectAtTime()`. Это штатный
  приём; без экспрешена подложка не повторяет длину текста, и панель об этом
  предупреждает.

### Честно про «растяжение времени и сложный микс»

Мы **не** угадываем итоговый звук композиции по параметрам слоёв — time remap,
экспрешены и эффекты на звуке делают это недостоверным. Вместо этого:

1. Простое растяжение слоя (`stretch`) учитывается точно — передаётся в движок.
2. При включённом time remap возвращаем предупреждение и предлагаем рендер.
3. Для «звука композиции» есть `renderCompAudio()` — временный дубль композиции
   и вывод в WAV через очередь рендера. Распознаём ровно то, что слышно.

## 3. Как запустить движок прямо сейчас (без After Effects)

```bash
cd engine
python3 -m pip install -r requirements.txt
python3 -m timpoc.cli doctor          # проверка окружения
python3 -m timpoc.cli models          # какие модели установлены
python3 -m timpoc.cli download --model small
python3 -m timpoc.cli transcribe звук.wav --out субтитры.srt
python3 -m timpoc.cli serve           # локальный сервер для панели
```

Тесты:

```bash
cd engine && python3 -m pytest -q          # 191 тест, ~50 с
python3 -m pytest -q -m "not integration"  # без распознавания, <1 с
```

## 4. Ограничения (без обещаний «100% точности»)

* **Точность распознавания конечна.** На русской речи разумный минимум — модель
  `small`, рекомендуется `medium`; `large-v3` лучше, но требует ~3 ГБ свободной памяти.
  `large-v3-turbo` быстрее, но заточен под английский.
* **Предпросмотр — приближение.** Метрики шрифта в браузере и в After Effects
  различаются. Точные размеры снимаются из AE через `measureText()`, итог всегда
  сверяется в композиции.
* **Слова после импорта SRT имеют приближённые тайминги** — переразбивка на фразы
  будет менее точной, чем после распознавания.
* **Подложка с выключенным экспрешеном** не повторяет длину текста.
* **CEP-панель с отладочной подписью** требует включённого режима разработчика;
  для обычной установки нужна подпись пакета (см. план установщика).

## 6. Что нужно проверить на вашем компьютере

Это нельзя проверить без After Effects, и я этого не делал:

1. Панель появляется в `Window → Extensions → timpoc — субтитры`.
2. `applySubtitles` создаёт текстовый слой с ключами Source Text, субтитры видны.
3. Названия свойств AE совпадают (`ADBE Drop Shadow-0001…0005`, `ADBE Rounded Corners`) —
   в разных версиях AE нумерация параметров эффекта может отличаться.
4. Экспрешен подложки считает размер корректно.
5. `Ctrl+Z` отменяет применение целиком.
6. `renderCompAudio` находит шаблон вывода WAV в вашей локали AE
   (в русской версии шаблон может называться иначе).
